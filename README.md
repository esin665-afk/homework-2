# Домашнее задание: Базовые SQL-запросы

## Описание проекта
В данном репозитории собраны SQL-запросы к базе данных `northwind`. 
Запросы разделены на три категории:
*   `simple_queries.sql` — простые выборки данных.
*   `filter_sorting.sql` — фильтрация, сортировка и математические операции.
*   `groupby.sql` — поиск по шаблону (LIKE), группировки, агрегатные функции и объединения (INTERSECT/EXCEPT).
